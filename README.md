# website

Le site de Gabin Simond, [gabin-simond.fr](https://gabin-simond.fr).

Une page statique en HTML et CSS, sans étape de build. Un seul petit script gère le choix du thème clair ou sombre. Les polices sont hébergées avec le site.

## Voir le site en local

```bash
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.
